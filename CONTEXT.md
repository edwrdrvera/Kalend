# Kalend — Glossary

## Space *(vision, not yet in code)*
A container a user creates for one recurring commitment: a class, a project, a job — anything with its own deadlines. Landing-page vocabulary only; the app's current code calls the equivalent concept a **Category** (color-coded tag on events/tasks). Whether "Space" replaces Category or sits above it as a new entity is an open question, deferred until this becomes real product work.

Resolved 2026-09-04: Kalend's positioning is being broadened from "student calendar" to a general tool organized around Spaces — a Space can be academic (a course) or not (a job, a freelance project). "Course" was rejected as the visible term because it reads academic-only.

## Class Schedule
Recurring calendar entries generated from a Space's timetable (e.g. "MWF 10am"). Toggleable per Space so the calendar doesn't get cluttered with recurring blocks the user doesn't want to see.

## Deadline
A dated item that belongs to a Space. Can carry a subtype (e.g. quiz, assignment) and a priority level. Can link to a Blocker/Reminder.

## Blocker / Reminder
Distinct from a Deadline. **Open question**: whether Blocker and Reminder are one category or two — described both ways in the same conversation, not yet resolved. Deferred.

## Calendar export
Syncing Kalend's calendar out to Google Calendar / Apple Calendar. Flagged by the user as a critical, must-have differentiator. Not yet built — appears in landing-page copy as vision/roadmap, not a shipped feature.
